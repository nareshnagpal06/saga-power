# saga-power

**saga-power** is a Power (skill package) for building AI agents on the Saga platform. It helps you create agents that interact with Saga APIs, MCP servers, and tools using Amazon Bedrock AgentCore and the Strands SDK.

Use it to onboard quickly: validate prerequisites, connect to Saga's domain-specific MCP servers (finance, payroll, and more), and deploy agents to AgentCore Runtime.

See [`POWER.md`](./POWER.md) for full setup, onboarding steps, and available MCP servers.
